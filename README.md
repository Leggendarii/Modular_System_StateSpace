# Modular System State-Space

This project is intended for modular state-space modeling and analysis of
power systems. It requires MATLAB and the external
[MATPOWER](https://matpower.org/) package; MATPOWER is not included in this
repository.

## Prerequisites

- MATLAB
- MATPOWER installed separately and available on the MATLAB path

Install MATPOWER by following its
[official installation instructions](https://matpower.org/about/get-started/).
No required MATPOWER version is specified in this repository.

## Project status

This repository currently contains only this README, a project description,
and the MIT license. It does not yet include source files or a build/run
entry point, so implementation details and usage commands cannot be documented
or verified yet.
